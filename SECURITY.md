# Security Policy

## Reporting Security Issues

The SOPS maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/getsops/sops/security/advisories/new) form.

For more details, see the [SOPS security policy](https://github.com/getsops/sops/blob/main/SECURITY.md).
